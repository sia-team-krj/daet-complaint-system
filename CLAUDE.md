# CLAUDE.md

This project keeps its agent rules in [AGENTS.md](AGENTS.md). Read it in full. The
"UI work" section is mandatory before any UI change.

Every change to `resources/views`, `resources/css`, `resources/js` or `lang` that
alters how the UI looks or behaves MUST add an entry to `docs/design-changelog.md`
in the same commit. Screenshots are optional (waived by the owner 2026-11-09);
verification evidence lives in the changelog entry — see `docs/ui-verification.md`.
